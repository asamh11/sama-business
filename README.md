# Sama Business: الأساس v0.1

## القرارات المعمارية
- **TypeScript صارم** للنواة: مال بـ `bigint` (وحدات صغرى)، بلا أرقام عشرية.
- **Postgres عبر Supabase** (دخول + قاعدة بيانات + RLS) بطبقة مجانية.
- **القواعد المحاسبية داخل قاعدة البيانات** وليس في الواجهة فقط: القيد المتوازن لكل عملة،
  عدم تعديل القيود أو حذفها (التصحيح بقيد عكسي)، عزل الشركات بـ RLS، الحفظ الذري،
  ومفتاح منع التكرار لكل عملية.
- **الذكاء الاصطناعي والصوت يجهّزان مسودة فقط** (`src/core/draft.ts`)، ولا ترحيل إلا بتأكيد مستخدم.
- **الاشتراكات بالأكواد**: تُخزَّن بصمة الكود فقط، والاسترداد ذري.

## التشغيل
```
npm test                      # اختبارات النواة (Node 22+)
supabase db reset             # يطبّق migrations على قاعدة محلية
```

## ما تم التحقق منه
- اختبارات النواة (7) ونجحت.
- ملف SQL **لم يُشغَّل بعد على Postgres** (البيئة هنا بلا قاعدة بيانات). أول خطوة عندك: `supabase db reset`
  وكتابة اختبارات pgTAP لعزل الشركات والقيد غير المتوازن.
