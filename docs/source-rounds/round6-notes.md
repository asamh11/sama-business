## الجولة 3: مالك منصة واحد غير مرئي (0005_platform_owner.sql)
- جدول `platform_owners` مغلق بـ RLS دون أي سياسة وبلا صلاحيات للأدوار العادية.
- `is_platform_owner()` تعيد true للمالك فقط. `owner_overview()` و`owner_issue_code()` ترفضان غير المالك.
- زر «لوحة المالك» لا يُرسم في الواجهة إلا إن أعادت القاعدة true.
- المالك يرى أعداداً فقط (الأعضاء والقيود والباقة) بلا مبالغ.
- تسجيل المالك يدوي فقط من SQL Editor:
  insert into platform_owners(user_id) select id from auth.users where email = 'بريدك';
- لم يُجرَّب على PostgreSQL.
